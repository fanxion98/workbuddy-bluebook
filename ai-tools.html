Cursor AI代码编辑器

基于 VS Code 构建的 AI 原生编辑器，2026年6月更新至 3.6 版本

Cursor 是目前最成熟的 AI 代码编辑器，被 Stripe、NVIDIA 等超过半数财富 500 强企业使用。2026年4月的 3.0 版本重构为 Agent-First 界面，支持多仓库并行操作、自主代理、云端交接等前沿能力。

核心功能

  • Composer 2.5：Cursor 自研前沿编码模型，200+ tok/s 生成速度，可同时编辑 10-100+ 个文件
  • 多代理并行：8个并行代理同时规划、编码、测试和修复，端到端实现功能
  • 代码库 RAG 索引：索引整个项目，理解架构和模式，500K 行代码库也能精准定位
  • 多模型支持：自由切换 Claude Opus 5、GPT-5.6、Gemini 3.1 Pro、Grok 4.5 等前沿模型
  • Cursor Router：智能路由，根据任务自动选择最佳模型（2026年7月新增）
  • 跨平台交接：桌面 / Web / 移动端 / Slack / GitHub / Linear 全平台覆盖

定价方案

方案月费核心权益
Hobby（免费）$02000 次补全 / 50 次高级请求
Pro$20/月无限补全 / 500 次快速请求 / Composer 多文件编辑

优势
  • 最流畅的 AI 编辑体验，Tab 补全预测多行编辑
  • 代码库理解能力业界第一
  • VS Code 基础，迁移成本极低
  • 更新频率高，功能迭代快
不足
  • 重度使用 Pro 额度不够，需升 Ultra
  • 闭源，无法自部署
  • 大 monorepo 索引时内存占用高
  • 高峰期请求可能降速

适合谁

追求最极致 AI 编程体验的开发者；VS Code 用户无缝迁移；需要多文件重构和代码库级对话的团队。结论：如果只选一个 AI 编程工具，选 Cursor。

扣子 Coze 零代码Bot搭建

字节跳动出品的零代码 AI Bot 搭建平台，注册即用

Coze 是字节跳动推出的 AI 应用/Bot 搭建平台，主打"零代码拖拽即上线"。内置 300+ 预置组件和插件市场，2 小时就能做出一个能用的对话机器人，是门槛最低的 AI 应用搭建工具。

核心功能

  • 可视化编排器：类 Figma 拖拽界面，零代码搭建 Bot
  • 300+ 预置组件：覆盖对话、搜索、生成、API 调用等场景
  • 多渠道发布：一键发布到飞书、微信公众号、抖音、微信等渠道
  • 插件市场：丰富的第三方插件，扩展 Bot 能力
  • 工作流编排：支持条件判断、循环、并行等逻辑
  • 知识库：上传文档/网页，Bot 基于知识回答

定价方案

方案费用说明
免费版¥0基础 Bot 搭建与发布，有调用限制
专业版按量付费更高调用额度、更多高级组件
优势
  • 零门槛，不写代码也能上手
  • 字节生态整合，飞书/抖音一键发布
  • 中文支持好，国内访问稳定
  • 免费版功能够用
不足
  • 工作流深度仅 10 层，复杂逻辑受限
  • 不支持私有化部署
  • 知识库 RAG 能力较弱
  • 工作流版本需手动备份

适合谁

非技术用户快速搭建对话机器人；运营/新媒体团队做内容生成 Bot；需要快速原型验证的场景。结论：想最快做出一个能用的 Bot，选 Coze。

Dify AI应用开发平台

开源企业级 LLM 应用开发与编排平台，GitHub 142K Stars

Dify 是目前最火的开源 AI 应用开发平台（v1.14.1，2026年5月更新），支持从知识导入→模型配置→应用开发→部署上线的全流程。核心强项是 RAG 知识库 + Agent 工作流编排，可私有化部署，满足企业数据合规需求。

核心功能

  • RAG 知识库：上传 PDF/Word/Excel，基于企业私有知识回答
  • 工作流 DAG 引擎：支持 50 层工作流深度，复杂条件判断
  • 模型网关：接入 GPT、Claude、DeepSeek、通义千问、本地模型
  • Prompt IDE：可视化提示词编辑和调试
  • API 输出：生成 API 接口，嵌入现有系统
  • 私有化部署：Docker 一键部署，数据完全可控

定价方案

方案费用说明
社区版免费Docker 自部署，全功能
云服务按量付费免运维，从 $59/月起
企业版定制私有化部署 + 技术支持

本地部署建议：4核 CPU + 8GB 内存，知识库索引时短暂需 16GB

优势
  • 开源免费，类 Apache 2.0 许可
  • RAG 能力强，支持复杂文档解析
  • 私有化部署，数据安全可控
  • 模型适配灵活，支持多模型切换
不足
  • 部署门槛比 Coze 高，需技术基础
  • 冷启动 3-5 秒，响应较慢
  • 连接器数量不如 n8n（400+）
  • 最大并发 200/s

适合谁

需要搭建带知识库的 AI 应用的技术团队；需要私有化部署的企业；需要把 AI 嵌入自己产品的开发者。结论：要做有深度的 AI 应用，选 Dify。

n8n 工作流自动化引擎

开源工作流自动化平台，400+ 连接器，GitHub 188K Stars

n8n 是最强大的通用工作流自动化引擎（stable v0.25.4，2026年5月更新），400+ 预置连接器覆盖几乎所有主流 SaaS。AI 只是它的一个节点，核心能力是把多个系统串起来自动运行。响应延迟仅 50-200ms，冷启动 <1 秒。

核心功能

  • 400+ 连接器：Slack、飞书、数据库、CRM、ERP、Webhook 全覆盖
  • 代码节点：支持 JavaScript/Python 自定义逻辑
  • 20 层工作流：支持串行/并行分支、子工作流
  • AI 节点：调用大模型作为工作流的一环
  • 定时触发：Cron 表达式 + 事件触发双模式
  • 自部署：Docker 一键部署，内存仅 ~300MB

定价方案

方案费用说明
自部署免费Docker 部署，fair-code 许可
Cloud Starter$20/月2500 次执行 / 5 个工作流
Cloud Pro$50/月10000 次执行 / 无限工作流
Enterprise定制SSO / RBAC / 日志审计

云成本参考：AWS t3.small 部署约 $23/月

优势
  • 连接器数量最多（400+）
  • 响应最快（50-200ms）
  • 部署最轻量（300MB 内存）
  • 代码灵活性最高
不足
  • AI 能力是插件级别，非核心
  • 纯知识库场景不如 RAGflow
  • 零代码用户上手有门槛
  • 工作流深度 20 层，不如 Dify（50层）

适合谁

需要串联多个系统做自动化的技术团队；需要定时任务、数据同步、通知推送的运维；需要 AI + 传统自动化混合架构的企业。结论：把活儿自动串起来，选 n8n。

Midjourney AI图像生成

业界领先的 AI 图像生成工具，艺术品质标杆

Midjourney 是 AI 图像生成领域的标杆产品，以出色的艺术质感和细节表现著称。2026年版本在写实风格、一致性角色、文字渲染方面大幅提升，支持网页版独立创作界面。

核心功能

  • 高质量图像生成：写实/插画/3D/概念艺术，多风格切换
  • 一致性角色：跨图保持角色外观一致（--cref 参数）
  • 图像编辑：局部重绘、扩图、风格转换
  • Vary 变体系统：精细调整生成结果的变体
  • 批量生成：支持批量任务和排队
  • 网页版：独立创作界面，不再依赖 Discord

定价方案

方案月费核心权益
Basic$10/月200 张/月 / 3 并发
Standard$30/月15h 快速模式 + 无限松弛模式
Pro$60/月30h 快速 + 隐私模式 + 12 并发
Mega$120/月60h 快速 + 12 并发
优势
  • 艺术品质业界第一
  • 风格多样性极强
  • 一致性角色功能实用
  • 社区活跃，灵感丰富
不足
  • 价格较高
  • 精确控制不如 Stable Diffusion
  • 中文提示词支持一般
  • 商用需注意版权条款

适合谁

设计师、插画师、内容创作者；需要高质量配图的自媒体和营销团队；追求艺术品质的创意工作者。结论：要最好的出图效果，选 Midjourney。

Sora AI视频生成

OpenAI 出品的 AI 视频生成工具，文本/图片转视频

Sora 是 OpenAI 推出的 AI 视频生成工具，能根据文本描述或图片生成高质量视频。2026年版本在时长、一致性、物理模拟方面显著提升，支持最长 60 秒视频生成。

核心功能

  • 文本生成视频：描述场景，AI 生成对应视频
  • 图片生成视频：上传图片，让静态画面动起来
  • 物理模拟：模拟真实物理效果（重力、碰撞、流体）
  • 一致性：长视频中保持角色和场景一致
  • 视频编辑：扩展、变速、风格转换
  • 多分辨率：支持 720p / 1080p / 4K 输出

定价方案

方案月费视频额度
ChatGPT Plus$20/月50 次/月（720p / 5秒）
ChatGPT Pro$200/月无限生成（含 1080p / 20秒）
API按量付费$0.10/秒（720p）
优势
  • 生成质量业界顶尖
  • 物理模拟逼真
  • 与 ChatGPT 生态整合
  • 支持图片转视频
不足
  • 价格较高，Pro 才有无限额度
  • 生成耗时较长（1-3 分钟）
  • 复杂场景偶尔出现瑕疵
  • 国内访问需特殊网络

适合谁

短视频创作者、广告制作团队、影视概念设计师；需要快速生成视频素材的营销人员；探索 AI 视频可能性的创作者。结论：要最好的 AI 视频效果，选 Sora。

选型建议：按场景选工具

写代码 → Cursor（日常编程首选，VS Code 用户无缝迁移）

做对话机器人 → Coze（零代码最快上线，字节生态一键发布）

生成图片 → Midjourney（艺术品质标杆）

生成视频 → Sora（物理模拟最逼真）

混合架构推荐：n8n（系统集成+触发器）+ Dify（LLM+RAG 应用层）是企业级最稳组合。n8n 负责外部系统集成，通过 HTTP 调 Dify API，Dify 专注 AI 逻辑，分工明确。
