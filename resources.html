1. 周报类4 个

模板 01周报结构化输出
我是【岗位】，本周做了【3件事】：1.……2.……3.……。下周计划：【3件事】。请按「本周成果+数据+下周计划」格式帮我整理成一份简洁周报，重点突出我做得好的部分，字数控制在300字以内。
适用场景每周五写周报，5分钟出初稿
模板 02数据型周报
我是运营，本周核心数据：【拉新200人/转化率15%/活跃度提升8%】。请结合这些数据写一份周报，重点说明数据背后的原因和下周优化方向，用数据讲故事，不要流水账。
适用场景有具体数据指标的岗位
模板 03项目进展汇报
项目名称：【XXX】，当前进度：【XX%】，本周完成：【事项列表】，遇到的问题：【问题描述】，下周计划：【计划】。请按「进度-成果-问题-计划」格式整理成项目周报，控制在200字内发给领导。
适用场景需要定期向领导汇报项目进展
模板 04跨部门周报同步
我们部门本周完成了【事项】，对贵部门的影响是【说明】。需要贵部门配合的是【具体需求】，期望完成时间是【时间】。请帮我写一段200字以内的跨部门周报同步文字，语言专业但不高高在上。
适用场景需要与其他部门协作配合的工作

1. 公众号自动化发文：一句话从选题到草稿入库

以前手动写稿、排版、上传，怎么也要 30-60 分钟。这套流程跑通后，你只需要做两件事：提供 AppID 和 AppSecret，在后台添加一个 IP 白名单。

1

Step 1 · 自动搜索资料

WorkBuddy 没有直接开始写，而是先去网上检索了最新的操作步骤，还顺带查了公众号自动发布的 API 接口文档。这一步保证了文章内容有据可查，不是 AI 瞎编的。

2

Step 2 · 生成完整推文

资料搜集完成后，自动生成结构完整的推文，包含：更换前的准备事项、5 步标准操作流程、紧急申诉方案、6 个高频问题 Q&A、一张操作速查表格。全文约 2000 字，开箱即用。

3

Step 3 · 引导配置 API 权限

写完内容后，WorkBuddy 主动提示需要提供公众号的 AppID 和 AppSecret，并说明在哪里找到。注意：AppSecret 在微信开发者平台「开发密钥」区生成，管理员扫码后自动生成，一定要保存好，这是自动发文章的重要凭证。

4

Step 4 · 自动处理 IP 白名单

第一次调用微信 API 时，遇到了 IP 白名单拦截。WorkBuddy 直接给出解决方案，并告诉你需要添加哪个 IP 地址。按提示操作，不到 1 分钟搞定。

5

Step 5 · 自动生成封面图

用代码生成了一张渐变风格的封面图，风格简洁专业，并自动上传至公众号永久素材库。

6

Step 6 · 一键创建图文草稿

最后调用微信草稿箱接口，封面、标题、摘要、正文全部打包上传，草稿直接出现在公众号后台 —— 你只需要点一下「发布」。

有边界感：遇到平台限制（比如未认证订阅号无法 API 群发），WorkBuddy 会如实告诉你，不会忽悠你。

2. ima 知识库自动喂养：让知识库自己长起来

来源：《ima知识库+WorkBuddy》与《还在手动整理ima？》两篇合并｜原作者实测：早上醒来，知识库已经被喂饱了

2

Step 2 · 安装微信公众号查询 Skill

在 WorkBuddy 技能页面搜索 wechat-article-search 并安装。使用时在对话框里同时选中 ima-skill 和 Wechat Article Search 两个技能。

Step 3 · 说出你想关注什么

4

Step 4 · 设置定时自动化推送

在 WorkBuddy 里点「自动化」→「添加」，输入提示词、选择时间，保存即可。以后每天早上你什么都不用做，到点就能收到一份整理好的「今日情报」。

3. 多 Agent 团队协作：把大项目拆给一支 AI 小队

来源：《Workbuddy进阶教程_多 Agent 团队协作》｜难度：进阶

WorkBuddy 支持启动多个 Agent 并行工作，就像一支专业团队 —— 研究员收集信息、分析师处理数据、设计师输出成果，同步进行，把完成时间从「所有任务相加」压缩到「最长那条子任务」。

1

Step 1 · 让 AI 创建团队

直接下指令：「我有一个大任务：制作一份完整的竞品分析报告，包括市场调研、数据分析和 PPT 输出。请帮我创建一个多 Agent 团队，合理分工并行完成。」

2

Step 2 · AI 自动分配角色

WorkBuddy 会自动规划角色，例如：研究员 Agent 负责市场数据收集与竞品信息爬取，分析师 Agent 负责数据处理与对比分析，设计师 Agent 负责 PPT 框架和视觉设计，主 Agent 负责汇总结果和最终输出。

3

Step 3 · 监控各 Agent 进度

随时问一句「请列出各 Agent 的当前任务状态」，就能看到并行工作的进展。

4

实战 · 竞品分析报告

Agent-A（调研员）搜集 3 家竞品公司的公开信息：官网、产品、定价、用户评价，整理成结构化数据表；Agent-B（分析师）基于 A 的数据做 SWOT 分析，找出差距和机会点；Agent-C（报告撰写）整合以上分析，撰写 15 页竞品分析报告并输出 Word。A 和 B 可并行，两者完成后 C 开始工作。

官方定位是「全场景职场 AI 智能体桌面工作台」。用人话翻译：你把任务交给它，它会自己规划步骤、操作电脑、处理文件，最后把结果交给你。

一句话描述任务，AI 自动拆解并执行多步骤操作

自主规划与交付

多模态内容生成

自动生成文档、表格、图表、PPT 等多种格式办公成果

多 Agent 并行处理

远程控制 Claw

通过企业微信 / QQ / 飞书 / 钉钉绑定，手机端远程操控电脑

本地运行

任务在本地执行，数据不出本地机器

它不是在和你聊天，而是真的在帮你干活。

3. 三种工作模式

输入框上方可以切换，选对模式比写对指令更省事。

Craft
直接开干

AI 接到任务立刻规划并执行。适合目标明确、容错高的日常任务。

Plan
先看方案再放行

AI 先输出执行方案，你确认后再执行。适合涉及文件操作、重要数据的任务。

Ask
只问不动手

只回答问题、给建议，不执行任何操作。适合拿不准、想先探探路的场景。

刚开始用，先试试 Craft 模式感受 AI 的执行能力；碰到重要任务，切换到 Plan 模式，先看方案再放行 —— 这样出错率低很多。

4. 七大核心模块

01
AI 对话
基础功能

自带三种工作模式：Craft 直接开干、Plan 先看方案再放行、Ask 只问不动手。刚开始用建议先试 Craft 感受执行能力，碰到重要任务切到 Plan，出错率低很多。

02
任务执行
核心能力

描述一个完整任务，它自动拆解步骤、逐步执行、最后交付结果。说得越清楚，做得越准。

03
插件 Plugins / MCP
扩展操作能力

基于 MCP 协议运行，安装后在后台静默待命。你直接提需求就行，不用特意说「用某某插件」，AI 会自己判断和调用。

04
技能 Skills
注入专业知识

如果说插件扩展的是 AI 的能力边界，那技能扩展的是知识深度。社区技能安装前，务必先用 skill-vetter 做安全审查 —— 技能本质是代码，来路不明的可能有风险。

05
专家 Experts
给 AI 一个专业身份

有名字和人设的垂直领域顾问。它不是通用 AI 在泛泛而谈，而是懂行的人在认真回答你的专业问题。

06
自动化 Automations
让任务自己跑

给任务设一个定时器，到点自动执行，结果还能推送到企业微信。设置好之后，这些事就从你的待办列表里消失了。

07
Claw 远程控制
手机指挥电脑

通过微信 / 企业微信绑定，人在外面发一条消息，办公室的电脑自动干活。建议用专门的微信小号或企业微信接入，隔离风险。

5. 插件与技能：别搞混了

这两个概念最容易混淆，但区别很关键。

对比维度插件 Plugins技能 Skills
本质插件 = 扩展 AI 的操作能力技能 = 给 AI 注入专业知识
解决的问题让 AI「能够做」某件事让 AI「懂得怎么做更好」
运行方式基于 MCP 协议，安装后后台静默待命按需加载，注入领域知识和工作流
调用方式直接提需求即可，AI 自己判断是否调用在对话框选中技能，或由 AI 自动匹配
安装入口左侧边栏「插件」→ 插件市场技能面板「安装技能」，粘贴社区安装指令

安装社区技能的安全提醒

技能本质上是代码，来路不明的技能可能存在安全风险。安装任何社区技能前，务必先用 skill-vetter 做安全审查，它会自动扫描这些红旗信号：

  • 有没有异常的网络访问行为
  • 有没有索要 API 密钥或密码
  • 有没有访问敏感目录（如 ~/.ssh）
遇到高风险提示，坚决不装。

自动化收口

把这整套流程设置成每周一自动触发，结果推送到企业微信。

插件是手，技能是脑，专家是人格。插件给 AI 装上工具手，让它能操作外部系统；技能给 AI 注入专业知识，让它懂得怎么做得更好；专家给 AI 一个专业身份，让它以专业视角来回答你。WorkBuddy 最大的价值不是单一功能的强大，而是各模块协同之后的整体效率提升。

10. 五个进阶技巧

任务描述要包含四个要素

身份、目标、范围、格式。描述越具体，结果越准，返工率越低。

用 Plan 模式处理重要任务

涉及文件操作、重要数据的任务，先用 Plan 模式看方案，确认没问题再执行。这个习惯能避免很多麻烦。

技能要组合使用

不要单独用一个技能，试试组合：feishu-doc 读取飞书文档 → summarize 提取关键信息 → humanizer 优化表达 → xiaohongshu 生成平台适配版本。

善用追问

做完第一步不满意，直接追问：「这个太长了，帮我压缩到 500 字」「换一种更轻松的表达方式」「把第二部分的逻辑重新梳理一下」。WorkBuddy 支持多轮对话，互动越多结果越好。

定期整理技能库

装了一堆技能但不用，会影响 AI 的判断效率。定期进去看一眼，把用不上的禁用或卸载。

12. 指令使用原则与常见错误

提示词优化原则

  • 具体明确：避免模糊，提供具体信息
  • 结构清晰：使用标准格式，便于解析
  • 目标导向：明确想要达到的效果
  • 适度详细：提供足够但不冗余的信息

常见错误避免

  • 过于简略：信息不足导致理解偏差
  • 过于复杂：信息过多影响处理效率
  • 格式混乱：非标准格式难以解析
  • 目标模糊：不清楚想要什么结果

进阶学习路径

  • 基础掌握：熟练使用常用提示词
  • 组合应用：学会组合多个提示词
  • 个性化：定制适合自己工作的提示词
  • 创新探索：尝试创造新的提示词用法
记住：好的提示词 = 明确目标 + 具体信息 + 标准格式。WorkBuddy 是工具，你是大脑。

13. 常见问题

WorkBuddy 完全免费吗？
基础功能免费，腾讯会赠送初始积分额度，具体以官网当前活动为准。积分用完后可通过日常活跃获取，或购买额外积分。
数据安全吗？文件会上传到服务器吗？
WorkBuddy 所有任务在本地运行，数据不出本地机器。官方承诺不收集用户的文件数据。需要注意的是，安装第三方技能时要谨慎，记得用 skill-vetter 先审查。
WorkBuddy 和 OpenClaw 是什么关系？
WorkBuddy 基于开源框架 OpenClaw 构建，完全兼容 OpenClaw 的技能生态，之前用过 OpenClaw 的话技能可以无缝迁移。两者最大的区别是：OpenClaw 更偏技术用户，需要一定的部署能力；WorkBuddy 面向普通用户，下载即用，无需配置。
电脑配置要求高吗？
普通的 Windows / Mac 电脑都能运行。建议内存 8 GB 以上，处理复杂任务时响应更流畅。
远程控制功能安全吗？
任务在本地执行，微信只是触发器，不传输文件内容。但建议不要用主微信号，专门用一个微信小号或企业微信号来接入，隔离风险。
技能安装失败了怎么办？
先检查 Node.js 和 Git 是否已安装并正确配置，然后检查网络连接。如果持续失败，可以重启 WorkBuddy 再试，或查阅官方文档的报错排查章节。
