买域名 + 绑定 GitHub Pages

我买了域名 simouxuan.com，帮我绑定到 GitHub Pages。仓库地址是 fanxion98/fanxion98.github.io

② 生成 DNS 配置说明 — 告诉你去 DNSPod 加这些记录：

149 个关键词策略 + 部署

核心概念：百度没有"提交关键词"功能。关键词写在 HTML 的 meta keywords 标签里，百度爬虫抓取页面时自动提取。

帮我想一些我个人博客的搜索关键词，要覆盖用户可能搜的各种词。博客主题是 WorkBuddy、AI Agent、AI办公、小鹅通、个人博客
WorkBuddy 做了
按内容主题整理了 6 大类共 149 个关键词：
品牌词：思陌选、小饭、小饭博客 WorkBuddy：教程、下载、Skills、案例 AI Agent：智能体、场景、案例、实战 AI办公：文档、数据分析、PPT、会议 小鹅通+电商：知识付费、店铺管理 长尾词：WorkBuddy vs Cursor、vs Copilot
💡 关键原则

不是把 149 个词全塞进一个页面。按页面主题分配：首页放全 6 大类做流量入口，子页面放垂直相关词。

页面关键词数分配策略
首页 index.html38 个全 6 大类，品牌词 + 核心词 + 长尾词
AI Agent案例20 个AI Agent 相关词为主
Skills技能15 个WorkBuddy + Skills 相关
使用手册17 个WorkBuddy 教程 + 下载 + 使用
其他 4 个页面各 14-16 个按页面内容分配相关词
这些关键词全部帮我加进去，按页面内容分配到对应的 meta keywords 标签里。8 个 HTML 文件都要改。
WorkBuddy 做了
写了一个 Python 脚本，用 re.sub 正则匹配每个文件的 <meta name="keywords" ...> 标签，替换为分配好的关键词。一次性改完 8 个文件。
# 脚本核心逻辑 import re # 每个页面分配的关键词 keywords_map = { "index.html": "思陌选,小饭,小饭博客,...（38个词）", "ai-agent-cases.html": "AI Agent,AI智能体,...（20个词）", "skills.html": "WorkBuddy Skills,...（15个词）", # ... 共8个文件 } # 正则替换 meta keywords for filename, keywords in keywords_map.items(): content = open(filename, "r", encoding="utf-8").read() new_content = re.sub( r'<meta name="keywords" content="[^"]*">', f'<meta name="keywords" content="{keywords}">', content ) open(filename, "w", encoding="utf-8").write(new_content) print(f"✅ {filename} → {len(keywords.split(','))} 个关键词")
验证
WorkBuddy 推送上线后，用 WebFetch 打开每个页面查看源代码 → 确认 meta keywords 标签里包含了分配的关键词。
8 个文件全部更新成功，149 个关键词全部上线。

3 条核心经验

  1. 先买域名再做 SEO — 没独立域名百度不收。域名年费几十元，不需要服务器。GitHub Pages 免费托管。
  2. 技术 SEO 不能省 — robots.txt、sitemap.xml、meta 标签是搜索引擎理解你网站的"语言"。WorkBuddy 一条指令批量改完。
  3. 主动提交比等抓取快 — 提交 sitemap + 逐个提交 URL，1-3 天被抓取。不提交可能等几周。关键词写在 meta keywords 里，百度爬虫自动提取。
💡 SEO 是慢活

从提交到首页排名一般 1-3 个月。基础设施搭好了，剩下就是持续产出内容和等。
