0背景：为什么要做SEO？

我的个人博客「小饭的 AI 实战笔记」托管在 GitHub Pages 上，内容涵盖 WorkBuddy 使用手册、AI Agent 案例、Skills 技能等 28 篇原创文章。但存在三个问题：

  • 没有独立域名 — 用的是 fanxion98.github.io，百度对 GitHub 子域名收录不友好
  • 没有任何SEO基础设施 — 没有 robots.txt、sitemap.xml、meta 标签、结构化数据
  • 百度完全收录不了 — 没有提交过百度站长平台，搜索引擎根本不知道这个网站存在

目标很简单：让百度能搜到「思陌选」「WorkBuddy 教程」「AI Agent 案例」这些关键词时，我的博客能出现在搜索结果里。

💡 核心思路

不是「写完文章等百度来抓」，而是主动出击：买域名 → 配DNS → 上HTTPS → 做技术SEO → 验证站长平台 → 提交sitemap → 布局关键词 → 提交URL。每一步都用 WorkBuddy 完成。

1域名购买与绑定

1.1 为什么需要独立域名？

GitHub Pages 默认提供 username.github.io 的子域名，但百度对这类域名的收录优先级很低。拥有独立域名有三个好处：

  • 百度更信任独立域名，收录概率大幅提升
  • 品牌识别度高 — simouxuan.com 比 fanxion98.github.io 好记
  • 未来迁移方便 — 域名跟着你走，不怕平台变动

1.2 操作步骤

在腾讯云购买了 simouxuan.com 域名（思陌选），然后通过 WorkBuddy 完成绑定：

  1. 在 GitHub 仓库根目录创建 CNAME 文件，内容为 www.simouxuan.com
  2. 在腾讯云 DNSPod 配置 DNS 解析：
    • 4 条 A 记录：@ → 185.199.108.153 / 109 / 110 / 111
    • 1 条 CNAME 记录：www → fanxion98.github.io
  3. 等待 DNS 生效（通常 10-30 分钟）
⚠️ 遇到的坑

DNSPod 免费版不支持境外解析，而 GitHub Pages 服务器在境外。解决方案：在 DNSPod 弹出的付费提示中填入 2 个 IP，再手动添加剩余 2 条 A 记录。另外，www 和不带 www 的域名只能选一个作为主域名，否则会出现 301 重定向问题（后面百度验证时踩了这个坑）。

1.3 www vs 不带 www

最初 CNAME 设为 simouxuan.com（不带 www），但百度站长平台验证 www.simouxuan.com 时，GitHub Pages 返回 301 重定向到不带 www 的域名，导致百度验证失败。

解决方案：把 CNAME 改为 www.simouxuan.com，让 www 成为主域名。修改后：

  • https://www.simouxuan.com → 200（不跳转）
  • https://simouxuan.com → 301 跳转到 www（正常行为）

2HTTPS 证书签发

域名绑定后，浏览器显示「不安全」，因为还没有 HTTPS 证书。GitHub Pages 支持自动签发 Let's Encrypt 证书，但需要等待。

操作方式

  • GitHub Pages 绑定自定义域名后会自动申请证书
  • 证书签发通常需要 10-30 分钟
  • 如果长时间未签发，用一个空 commit 触发重新部署：git commit --allow-empty -m "触发重新部署"
✅ 结果

空 commit 推送后约 30 分钟，HTTPS 证书签发成功。https://www.simouxuan.com 正常访问，SSL 证书有效期至 10 月 28 日。

4百度站长平台验证

4.1 验证方式选择

百度站长平台提供三种验证方式：HTML 标签验证、文件验证、CNAME 验证。最初尝试 HTML 标签验证，但因为 GitHub Pages 强制 HTTPS 导致 301 跳转，验证失败。改用文件验证：

  1. 在百度站长平台下载验证文件 baidu_verify_codeva-nJSG61v6a6.html
  2. 通过 GitHub 网页端上传到仓库根目录
  3. 等待 GitHub Pages 部署（1-3 分钟）
  4. 访问 https://www.simouxuan.com/baidu_verify_codeva-nJSG61v6a6.html 确认返回 200 + 正确内容
  5. 回百度站长平台点「完成验证」

4.2 踩坑：www 域名 301 问题

验证时百度请求的是 www.simouxuan.com，但 CNAME 写的是不带 www 的 simouxuan.com，GitHub Pages 返回 301 重定向，百度认为验证失败。

解决方案：把 CNAME 改为 www.simouxuan.com，让 www 成为主域名。修改后验证立即通过。

✅ 验证结果

百度站长平台验证通过，网站 www.simouxuan.com 正式被百度收录系统识别。

核心经验总结

  1. 先买域名再做SEO — 没有独立域名，百度对 GitHub 子域名的收录极不友好。域名是 SEO 的第一步，年费几十元，性价比极高。
  2. www 和不带 www 只能选一个 — 百度验证时会因为 301 重定向失败。提前确定主域名，CNAME 写主域名，另一个自动跳转。
  3. 技术SEO不是可选项 — robots.txt、sitemap.xml、meta 标签、JSON-LD 结构化数据，这些是搜索引擎理解你网站的「语言」。没有它们，百度不知道你有什么页面、每个页面讲什么。
  4. 关键词要按页面分配 — 不是把所有关键词堆到首页，而是按内容主题分配到不同页面。首页做流量入口放全部大类，子页面放垂直领域词，形成关键词矩阵。
  5. 移动适配影响排名 — 百度对移动端友好的网站给予更高排名。两档响应式断点（900px/480px）覆盖了从平板到手机的全部场景。
  6. 主动提交比等抓取快 — sitemap 提交 + URL 逐个提交，比被动等百度爬虫发现快得多。提交后 1-3 天就能被抓取，不提交可能要等几周。
  7. WorkBuddy 让 SEO 变成对话式操作 — 从域名绑定到关键词部署，每一步都是用自然语言跟 WorkBuddy 说了需求，它用 Python 脚本批量处理。一个人一下午完成了传统SEO公司几天的工作量。

9后续规划

  • 2-4 周后查看收录情况 — 在百度搜索「思陌选」或核心关键词，查看是否被收录
  • 持续产出优质内容 — 内容质量是排名的核心因素，文章越专业收录越快
  • 做外链建设 — 在知乎、公众号等平台发布文章并链接到博客，提升域名权重
  • 提交搜狗/360 站长平台 — 除了百度，其他搜索引擎也要覆盖
  • 监控索引量 — 在百度站长平台「索引量」页面查看每天收录的页面数
💡 SEO 是慢活

从提交到首页排名一般需要 1-3 个月。关键看三个因素：内容质量、外链数量、用户行为数据（点击率、停留时间）。基础设施已经搭好了，剩下就是持续运营。
