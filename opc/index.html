定义

什么是超级个体？

人即产品

单人（+少量助理）≈ 一家公司。收入来自系统 / 产品 / 内容，而非出售时间。

不靠组织

不依赖单一雇主。拥有自己的客户、资产与品牌，主动定义价值。

变好而非变大

拒绝盲目扩张。小而精、抗风险、工作即生活——这是「一人企业」的哲学。

"超级个体 = (专长 × 杠杆) + 个人品牌 + 经营者心智 + 多元能力 + 长期主义。其中杠杆 = 代码 / 媒体 / 资本 / AI。" 综合自《纳瓦尔宝典》《一人企业》《单干》
