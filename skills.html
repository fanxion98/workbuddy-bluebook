公众号文章自动写作与发布
热门 内容创作
技能概述
通过 WorkBuddy 的 wechat-write 和 wechat-publisher 技能，实现从选题到发布的全自动化公众号内容工作流。支持刘润风格写作、AI 生成封面图、自动排版推送草稿箱。
部署方法
  • 1. 在 WorkBuddy 中打开「技能中心」，搜索并安装 wechat-write 技能（公众号文案创作）
  • 2. 安装 wechat-publisher 技能（Markdown 转公众号草稿箱）
  • 3. 在 .env 文件中配置公众号凭据：WECHAT_APPID=wx8d42f044a0d55711, WECHAT_APPSECRET=你的密钥
  • 4. 安装 wenyan-cli 工具：npm install -g @wenyan-md/cli
  • 5. 在微信公众号后台「设置-开发-IP白名单」中添加你的服务器IP
  • 6. 安装 wechat-article-pro 技能（专业版，支持AI配图和刘润风格）
使用步骤
  1. 输入指令：「帮我写一篇关于XX主题的公众号文章，刘润风格」
  2. AI 自动生成 3000-5000 字文章，含标题、正文、配图建议
  3. 输入指令：「用 ImageGen 生成一张封面图，主题是XX」
  4. 输入指令：「推送到公众号草稿箱」
  5. wenyan-cli 自动排版（lapis 主题 + solarized-light 代码高亮）并上传
  6. 登录公众号后台审核草稿，确认后发布
示例指令
帮我写一篇关于「AI Agent 如何改变教培行业」的公众号文章，要求：刘润风格、案例驱动、3000字左右、有数据支撑。写完后用 ImageGen 生成封面图，然后推送到草稿箱。
应用场景
每日公众号内容自动化生产，从选题到草稿箱全程无人值守
热点事件快速响应，30分钟内完成选题-写作-配图-推送全流程
多账号矩阵运营，一次生成多版本适配不同公众号定位

股票综合分析
金融 金融数据
技能概述
使用 stock-analyzer 技能，输入股票名称或代码，自动从东方财富网获取数据，进行基本面、新闻面、资金面三维分析，输出投资建议和买卖点位。
部署方法
  • 1. 在 WorkBuddy 技能中心安装 stock-analyzer 技能
  • 2. 该技能内置东方财富网数据接口，无需额外配置API密钥
  • 3. 支持A股、港股、美股等东方财富覆盖的所有市场
  • 4. 确保网络能正常访问东方财富网（eastmoney.com）
使用步骤
  1. 输入指令：「分析一下贵州茅台这只股票」或「分析股票 600519」
  2. 技能自动获取股票基本信息、财务数据、近期新闻
  3. AI 进行三维分析：基本面（PE/PB/ROE/营收增速）、新闻面（利好利空事件）、资金面（主力资金流向）
  4. 输出分析报告，包含投资建议、建议买入价位、建议卖出价位
  5. 可追加指令：「帮我监控这只股票，每天早上8点推送分析」
示例指令
帮我分析一下宁德时代（300750），重点关注最近的新能源行业政策和三季报数据，给出短期和长期的投资建议。
应用场景
个股深度分析，辅助投资决策
每日持仓股票自动巡检，异常波动及时预警
行业板块对比分析，发现投资机会

小红书海报批量生成
设计 内容创作
技能概述
通过 Python Pillow 库 + 预设海报模板，根据文章内容自动生成小红书风格的海报图片。支持多种排版模板、配色方案和字体选择。
部署方法
  • 1. WorkBuddy 已内置 Python 3.13 环境，无需额外安装
  • 2. 安装 Pillow 图像处理库：pip install Pillow
  • 3. 准备字体文件（思源黑体/阿里巴巴普惠体），放在项目 fonts 目录
  • 4. 将海报模板图片放在 templates 目录
  • 5. 可选：安装 build_posters.py 脚本（WorkBuddy 自动生成）
使用步骤
  1. 输入指令：「根据这篇文章内容帮我做10张小红书海报」
  2. AI 分析文章内容，提取关键要点和金句
  3. 自动选择适合的海报模板（知识分享/好物推荐/教程类）
  4. Pillow 自动渲染：背景图 + 标题文字 + 正文要点 + 品牌水印
  5. 批量生成10张海报，输出到 posters/ 目录
  6. 可追加指令：「换一套配色方案，用莫兰迪色系重新生成」
示例指令
帮我根据这篇公众号文章做10张小红书海报，要求：尺寸 1080x1440，配色用粉色系，每张海报一个核心要点，底部加「小饭的AI实战笔记」水印。
应用场景
公众号文章转小红书图文，一鱼多吃
知识卡片批量制作，适合教育类内容传播
活动宣传海报快速生成，10分钟出10张

使用步骤

  2. 技能调用企查查 API，返回企业基本信息（注册资本、法人、成立日期）

  4. 可追问：「这家公司有哪些对外投资？高管团队是谁？」
  5. 可追问：「导出为 Excel 格式的尽调报告」

定时自动化任务
效率 效率工具
技能概述
使用 WorkBuddy 内置的 automation_update 工具，创建定时自动化任务。支持每日、每周、每月循环执行，也可设置一次性定时提醒。任务存储在本地 SQLite 数据库中。
部署方法
  • 1. 无需额外安装，WorkBuddy 内置 automation_update 工具
  • 2. 支持 RFC 5545 RRULE 标准的定时规则
  • 3. 可设置任务有效期（validFrom / validUntil）
  • 4. 可关联特定的工作目录和专家ID
  • 5. 任务状态管理：ACTIVE（激活）/ PAUSED（暂停）
使用步骤
  1. 输入指令：「每天早上8点帮我查看WorkBuddy的最新活动并整理成简报」
  2. AI 创建自动化任务，scheduleType=recurring，rrule=FREQ=DAILY;HOUR=8
  3. 每天8点自动执行：抓取活动信息 → 整理简报 → 输出到对话
  4. 管理任务：「查看我所有的自动化任务」→ 列出所有任务
  5. 暂停任务：「暂停XX任务」→ status=PAUSED
  6. 删除任务：「删除XX任务」→ 软删除，可恢复
示例指令
帮我设置一个自动化任务：每周一早上9点，分析上周的A股市场表现，整理成周报格式，包含板块涨跌幅、北向资金流向、重点个股分析。
应用场景
每日数据监控（股价、新闻、竞品动态）自动推送
周报/月报自动生成，减少重复劳动
定时提醒（会议、截止日期、待办事项）

视频特效制作
创意 AI 创作
技能概述
使用 buddy-multimodal-generation 技能的视频特效功能，基于预设模板对图片应用动效。支持拥抱、变身、万物归尘等热门特效模板。
部署方法
  • 1. 该技能为 WorkBuddy 内置技能
  • 2. 在对话中说「对图片应用特效」即可触发
  • 3. 需要提供一张输入图片作为特效素材
  • 4. 选择特效模板（拥抱/变身/万物归尘等）
  • 5. 生成的视频保存为 MP4 格式
使用步骤
  1. 上传一张人物照片
  2. 输入指令：「对这张图应用拥抱特效模板」
  3. AI 识别图片内容，匹配特效模板
  4. 等待1-3分钟生成视频特效
  5. 视频保存为本地 MP4 文件
  6. 可在对话中预览效果，不满意可重新生成
示例指令
我上传了一张我奶奶的旧照片，帮我用「拥抱」特效模板生成一个视频，让照片里的人物动起来，像是在拥抱的效果。
应用场景
老照片动效制作，让回忆鲜活起来
社交媒体创意内容制作
节日祝福视频快速生成

小鹅通打通 WorkBuddy 流程
核心 知识付费
技能概述
小鹅通是国内主流的知识付费与私域运营平台，WorkBuddy 是 AI Agent 工作平台。通过 xiaoe-claw 技能和 xiaoe-cloud-cli 连接器，把两个平台打通：在小鹅通里产生的课程、订单、用户、学习数据，可以自动同步到 WorkBuddy，由 AI Agent 进行内容生产、用户分层、运营动作和数据分析。
部署方法
  • 1. 在 WorkBuddy 技能中心安装「xiaoe-claw」技能（小鹅通店铺全能管理助手）
  • 2. 在 WorkBuddy 连接器管理中启用「xiaoe-cloud-cli」小鹅通连接器
  • 3. 准备小鹅通商家账号，并确保有店铺管理员权限
  • 4. 登录小鹅通开放平台（https://xiaoe-tech.com/），创建应用获取 AppID 和 AppSecret
  • 5. 在 WorkBuddy 的 .env 或 MCP 配置中填入：XIAOE_APPID=你的AppID, XIAOE_APPSECRET=你的AppSecret
  • 6. 点击连接器「信任」按钮完成授权，测试连接：「查看我店铺里所有上架的商品」
  • 7. 如需知识库联动，开启 ima 或知识库连接器，把课程内容同步给 WorkBuddy 做问答调用

  2. 订单数据打通：「查询最近7天的订单，按金额排序，导出到 Excel」
  3. 用户画像分析：「分析店铺用户画像，付费用户有多少，复购率是多少」
